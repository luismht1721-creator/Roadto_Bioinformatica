# Ruta de agronomía a la bioinformática

Programa de aprendizaje autodirigido de 9 meses, diseñado como preparación para postular
a un MSc en Bioinformática (Wageningen) o al Computational Biology & Bioinformatics de ETH Zürich.

La meta del programa no es solo estudiar: es producir un **artefacto de investigación público**
(un repositorio documentado + un preprint en bioRxiv) que sirva como carta de admisión real
ante un comité y como puente para contactar a un profesor.

## Cómo usarlo

Abre `index.html` en cualquier navegador (doble clic). No requiere instalación, build ni conexión a internet.

- Las fases se despliegan al hacer clic.
- Marca cada hito conforme lo completes.
- El progreso se guarda automáticamente en `localStorage` de tu navegador.

> El progreso se almacena **por navegador y por equipo**. Si limpias los datos del navegador
> o lo abres en otra máquina, empieza de cero.

### Publicarlo en la web (GitHub Pages)

Como el archivo se llama `index.html`, puedes servirlo gratis:
1. En tu repositorio de GitHub: **Settings → Pages**.
2. En *Source*, elige la rama `main` y la carpeta `/ (root)`.
3. Tu programa quedará disponible en `https://<tu-usuario>.github.io/ruta-bioinformatica/`.
